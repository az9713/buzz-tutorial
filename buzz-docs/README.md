# buzz-docs

The four files in this folder (`index.md`, `key-concepts.md`,
`troubleshooting/common-issues.md`, `user-guide/using-your-ai-subscription.md`)
are **proposed additions to [`block/buzz`](https://github.com/block/buzz)**,
written to be dropped into that repo's `docs/` directory.

Their relative links are written **as if each file already sat at
`buzz/docs/...`** in the upstream repo — for example `../README.md`,
`../ARCHITECTURE.md`, `nips/NIP-CW.md`. **They will not resolve from where
these files currently sit** in `buzz-tutorial`. To use them, copy this
folder's contents into the upstream `block/buzz` clone at `docs/`
(so `buzz-docs/index.md` → `buzz/docs/index.md`,
`buzz-docs/troubleshooting/common-issues.md` → `buzz/docs/troubleshooting/common-issues.md`,
and so on) and the links will resolve correctly there.
